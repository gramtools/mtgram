## Протоколы

VLESS, VMess, Trojan, Shadowsocks, Hysteria2, XHTTP и REALITY. В списке серверов у каждого сразу видно, какой протокол используется и какой у него отклик.

## Приложение

**Автовыбор.** Само берёт лучший сервер из ключа, перебирать список не нужно.

**Трафик и срок.** Остаток трафика и дата окончания видны на главном экране.

**IPv6.** Поддерживается IPv6, включая DNS.

## Без логов

Аккаунта нет. Приложение не собирает логи и не отправляет аналитику. Ключ и настройки остаются на устройстве. Доступ приложение не продаёт.
